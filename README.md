# DesaKarya — BUMDes Website (GitHub Pages Ready)

Website statis HTML/CSS/JavaScript yang siap di-upload ke GitHub Pages.

## Struktur
- index.html  → halaman utama
- style.css   → seluruh desain
- script.js   → menu mobile
- images/     → gambar artikel

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `desakarya-bumdes`.
2. Upload SEMUA isi folder ini (bukan folder induknya) ke repository.
3. Pastikan `index.html` berada di bagian paling atas/root repository.
4. Buka Settings → Pages.
5. Pada bagian Build and deployment, pilih Source: Deploy from a branch.
6. Pilih branch `main` dan folder `/ (root)`, lalu Save.
7. Tunggu proses deployment selesai.
8. Buka alamat Pages yang diberikan GitHub.

## Edit manual
- Nama website, teks, angka, menu: edit `index.html`.
- Warna, ukuran, jarak, layout: edit `style.css`.
- Interaksi menu HP: edit `script.js`.
- Gambar: ganti file di folder `images/` dengan nama file yang sama.

## Catatan
Data statistik, nama BUM Desa, email, dan artikel pada template ini adalah contoh.
Ganti dengan data milik proyek/organisasi kamu sebelum dipublikasikan.
Website ini merupakan desain original yang terinspirasi dari pola portal BUM Desa, bukan salinan identitas atau konten situs pihak lain.
